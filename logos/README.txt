THƯ VIỆN LOGO CỦA NQS CHART BUILDER

Đặt file logo vào thư mục này trước khi đóng gói (npm run dist).
Logo sẽ được đóng gói sẵn vào file .exe, người dùng không cần chọn thư mục.

Quy cách đặt tên:
- Tên file = tên danh mục trong bảng (công ty, đơn vị...).
- Không cần chú ý dấu tiếng Việt, chữ hoa/thường, dấu cách, gạch ngang hay gạch dưới.
- Ví dụ: VPS.png, SSI.png, Mirae Asset.png, VN-Direct.jpg đều khớp với danh mục
  "VPS", "SSI", "Mirae Asset", "VNDirect".
- Đuôi được chấp nhận: .png, .jpg, .jpeg, .webp, .svg
- Nên dùng ảnh nền trong suốt, mỗi file dưới 1 MB.

PHÂN BIỆT NGÂN HÀNG VÀ CÔNG TY CHỨNG KHOÁN (tránh nhầm logo):
- Ngân hàng: dùng tên ngân hàng thường gọi, không thêm hậu tố.
    BIDV, VietinBank, Vietcombank, MB, VPBank, Techcombank, HDBank, ACB, Sacombank, SHB
- Công ty chứng khoán: dùng tên công ty chứng khoán; công ty thuộc ngân hàng thì
  dùng tên riêng của công ty, KHÔNG dùng tên ngân hàng.
    TCBS (của Techcombank), VPBankS (của VPBank), MBS (của MB), ACBS (của ACB),
    VCBS (của Vietcombank)
    Các công ty độc lập: SSI, VPS, VNDirect, HSC, Vietcap, Mirae Asset, LPS, VIX, DNSE
- Khi thêm logo mới: kiểm tra tên chưa trùng với file có sẵn (ví dụ "MB" là ngân hàng,
  "MBS" là chứng khoán), và đặt tên đúng như cách danh mục được viết trong bảng dữ liệu.

Lưu ý: khi thay đổi logo, phải đóng gói lại app để logo mới có hiệu lực.
