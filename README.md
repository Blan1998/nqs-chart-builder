# NQS Chart Builder

## Chạy thử
    npm install
    npm run dev

## Kiểm tra đặc tả
    npm test

## Đóng gói
    npm run dist

## Cấu trúc
- electron/   Tiến trình chính và cầu nối an toàn (preload)
- src/        Giao diện React
- src/specs/  Đặc tả từng loại biểu đồ (nguồn sự thật cho cả app)
- scripts/    Công cụ kiểm tra
